Metrics
Alignment
Replays ratings using only this entity's votes, then compares the model ranking to the filtered consensus (Kendall's τ). 1 = identical ranking, 0 = uncorrelated, −1 = reversed. Above 0.6 is strong agreement; below 0.2 is near-random. Values shift when you exclude annotators or data points because the consensus changes.
Influence
Removes the entity, replays Glicko-2, measures total rating shift divided by vote count. Naturally uncertainty-weighted: shifts are large when the entity's votes hit models with wide RDs and shrink as models settle. Compare within an arena, not across.
Rank Shifts
How many models change leaderboard position when this entity is removed. Ranges from 0 to N (number of models). 0 = no effect on ordering.
Consensus Δ (data only)
Change in average annotator alignment when this data point is removed. + = removing it improves consensus (noisy/controversial). − = removing it hurts consensus (stabilizing). Values near 0 have little effect.
Pairwise Alignment
Kendall's τ between each pair of annotators' solo rating rankings (−1 to 1). Green = agree on model ordering, red = disagree.
Time to first vote
Wall-clock seconds from when the match becomes votable to when the annotator submits their first verdict on it (vote or skip on any criterion). Captures how long the annotator spent perceiving the scene before committing to anything. Time while the browser tab is in the background (minimized, on a different tab) is subtracted; a single vote taking longer than 10 minutes is recorded as N/A on the assumption the annotator stepped away.
Time per match
Total wall-clock seconds an annotator spent on a match, summed across every criterion (votes and skips). Same background-tab subtraction and 10-minute-per-criterion outlier rule apply.

Arenas

Each arena is a blind A/B evaluation between two models on the same input. You vote on which output is better without knowing which model produced it. Votes update per-model Glicko-2 ratings.

Publish / Unpublish: Unpublished arenas are only visible to owners and admins. Publish to make an arena visible to all users.

Refresh Manifest: Re-fetches the arena's manifest from S3. Use this after updating models, items, or instructions on S3 without restarting the server.

Creating a new arena: Upload a manifest.json and asset files to S3 under arenas/{name}/assets/{item_id}/. The server auto-discovers it within 60 seconds.
