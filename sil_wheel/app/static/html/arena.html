Arenas

Each arena is a blind A/B evaluation between two models on the same input. You vote on which output is better without knowing which model produced it. Votes update ELO ratings.

Publish / Unpublish: Unpublished arenas are only visible to owners and admins. Publish to make an arena visible to all users.

Refresh Manifest: Re-fetches the arena's manifest from S3. Use this after updating models, items, or instructions on S3 without restarting the server.

Creating a new arena: Upload a manifest.json and asset files to S3 under arenas/{name}/assets/{item_id}/. The server auto-discovers it within 60 seconds.
