# SIL Wheel Overview

## What Is SIL Wheel?

SIL Wheel is an interactive data exploration server for browsing, searching, annotating, and inspecting autonomous vehicle (AV) training clips. It streams videos from S3 and supports multi-modal search across 18M+ indexed driving clips.

- **Production server**: http://your-sil-wheel-host:8000
- **Dev server**: http://localhost:8018 (sandbox for write operations)
- **GitLab repo**: https://github.com/nv-tlabs/sil-wheel (project ID 146260)
- **Owner**: your SIL Wheel administrator

## Cosmos Embeddings

The backbone of similarity search:
- **Model**: Cosmos-Embed1 (768-dim vectors)
- **Index**: FAISS IVF4096,PQ96x8 (2GB index + 787MB clip mapping)
- **Coverage**: 18M+ clips indexed
- **Capabilities**: Text-to-video (requires model inference) and clip-to-clip (FAISS lookup)

## Classifiers

Trained logistic regression models on Cosmos embeddings:
- 93 trained classifiers on production (Snow, Construction zone, night, tunnel, interesting, HighDynamicMotion, little_scene_dynamics, High curvature road, and many more)
- Training: ~50 positive labels + random negatives -> scores ALL indexed clips
- Scores stored as per-label `predicted_scores.json`
- Classifier weights exportable as JSON via `/classifier/export/<label>`

## Captions

- Generated by Qwen2.5-7B on 10-second video windows
- Stored in SQLite with FTS5 full-text search index
- Caption DB: ~94GB on production
- LLM query rewriter available (expands searches using NV Inference API)

## Trajectory Data

- 605 timestep trajectories per clip (20s at ~30 FPS, downsampled)
- Features: position (x,y), heading, speed, acceleration, jerk, curvature
- Three FAISS indexes for shape similarity (full 20s, 10s window, 5s window)
- Predicate search with arbitrary Python expressions
- Named patterns: high_curvature, stop_go, hard_braking, prolonged_stop, idle_to_cruise, high_speed_swerve, moving_ego

## Clustering

- K-means clustering over Cosmos embeddings (spherical or Euclidean)
- On-demand runs from the UI or API
- Results include: cluster representatives, cluster sizes, UMAP visualizations
- Cluster search mode filters clips by cluster membership, ranked by centroid distance

## Browser Deep Links

The frontend uses hash-based routing (`clip_url()` appends `&project_source=Alpamayo` by default):
- **View a clip**: `http://your-sil-wheel-host:8000/#&page=0&search_clipid={clip_id}&project_source=Alpamayo`
- **Caption search**: `http://your-sil-wheel-host:8000/#&page=0&search={query}`
- **Classifier filter**: `http://your-sil-wheel-host:8000/#&page=0&classifier_select={label}&probability_threshold=0.5`
- **Combined search**: Chain any parameters with `&`

The `WheelClient` provides `clip_url()` and `search_url()` helpers to generate these.
